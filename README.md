# Docker Zanthus

## 📄 Descrição
Repositório destinado a reunir os arquivos e scripts relacionados ao Docker Zanthus, mantendo os recursos necessários organizados em um único lugar.

## 🎯 Objetivo
Facilitar a instalação e a inicialização do ambiente, permitindo que os arquivos necessários sejam encontrados e utilizados de forma rápida e organizada.

## 📁 Estrutura de pastas e arquivos

    Docker/
    ├── Install/
    │   ├── instalar.sh
    │   │
    │   └── dependencias/
    │       └── instalar_dependencias.sh
    ├── configuracao/
    │   └── docker-compose.yml
    ├── iniciar.sh
    └── README.md

## 📝 Descrição dos arquivos e pastas

- **Install/**: pasta com os arquivos de instalação.
  - **instalar.sh**: script de instalação.
  - **dependencias/**: pasta com os arquivos de instalação das dependências.
    - **instalar_dependencias.sh**: script de instalação das dependências.
- **configuracao/**: pasta com os arquivos de configuração do Docker.
  - **docker-compose.yml**: arquivo que define os serviços e configurações dos containers.
- **iniciar.sh**: script para iniciar o ambiente.
- **README.md**: arquivo com a documentação do repositório.
