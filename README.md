# Docker Zanthus

📄 Descrição
Repositório destinado a reunir os arquivos e scripts relacionados ao Docker Zanthus, mantendo os recursos necessários organizados em um único lugar.

🎯 Objetivo
Facilitar a instalação e a inicialização do ambiente, permitindo que os arquivos necessários sejam encontrados e utilizados de forma rápida e organizada.

📁 Estrutura do repositório
Install/ — Arquivos necessários para a instalação.
inicializacao/ — Script para iniciar o Docker Zanthus.


📁 Estrutura de pastas e arquivos
text
Docker/
├── Install/
│   ├── instalar.sh
│   └── dependencias/
│       └── instalar_dependencias.sh
├── configuracao/
│   └── docker-compose.yml
├── iniciar.sh
└── README.md

Descrição das pastas e arquivos
Install/: contém os arquivos relacionados à instalação.
instalar.sh: script de instalação do ambiente.
dependencias/: reúne os arquivos para instalação das dependências.
instalar_dependencias.sh: script de instalação das dependências.
configuracao/: armazena os arquivos de configuração do Docker.
docker-compose.yml: define os serviços e as configurações dos containers.
iniciar.sh: script utilizado para iniciar o ambiente.
README.md: documentação do repositório.
